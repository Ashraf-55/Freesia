# فريسيا Freesia — Next.js Rebuild

إعادة بناء مشروع فريسيا بالستاك المطلوب:
**Next.js + React + TypeScript + Tailwind CSS + SQLite + Prisma + Auth.js**

نفس البيانات، نفس الصور واللوجو، نفس الأسعار والمنطق — لكن بستاك حديث بالكامل.

---

## 1) التشغيل محليًا

```bash
# 1. ثبّتي الباكدجات
npm install

# 2. مفيش سيرفر داتا بيز مطلوب — SQLite ملف محلي جوه المشروع
cp .env.example .env
# افتحي .env واملي:
#   AUTH_SECRET  (نفذي: npx auth secret)
#   FREESIA_FORMSPREE_ENDPOINT (اختياري)

# 3. أنشئي الجداول
npx prisma migrate dev --name init

# 4. زرعي البيانات (نفس بيانات seed.py الأصلية — 73 منتج + 3 حسابات تجريبية)
npm run db:seed

# 5. شغّلي السيرفر
npm run dev
```

افتحي المتصفح على: **http://localhost:3000**

### حسابات تجريبية (زي الأصل بالظبط):
| الدور | البريد الإلكتروني | كلمة المرور | الدخول من |

| Admin | admin@freesia.test | Admin@12345 | /staff-login |
| Employee | sara@freesia.test | Employee@123 | /staff-login |

## 2) حالة المشروع

### مكتمل بالكامل
- **المرحلة 1 (الأساس):** Prisma schema كاملة، Auth.js بنظام صلاحيات، middleware حماية، الصور واللوجو، seed script
- **المرحلة 2 (المتجر):** الرئيسية، الفئات، المنتج، البحث، السلة، المفضلة، Checkout، تأكيد الطلب، صفحة الحساب وسجل الطلبات، تواصل معنا (Formspree)
- **المرحلة 3 (لوحة الأدمن):** Dashboard بأرقام حقيقية، إدارة المنتجات (إضافة/تعديل/حذف)، إدارة الطلبات (فلترة + تغيير الحالة + حذف)، إدارة العملاء، المخزون، التقارير (مبيعات حسب الحالة، الأكثر مبيعًا، مخزون منخفض)
- **المرحلة 4 (الموظفين والصلاحيات):** صفحة الموظفين — إضافة موظف، تغيير كلمة مرور، تفعيل/تعطيل، حذف، وإدارة صلاحيات كل موظف تفصيليًا (بنفس منطق الأصل: الموظف مايقدرش يعدّل صلاحياته الخاصة، ومفيش أي مسار ممكن يعمل موظف بدور admin)
- **المرحلة 5 (Formspree):** نموذج تواصل معنا شغال ومربوط بمتغيّر البيئة

### باقي (اختياري — تحسينات إضافية)
- رفع صور المنتجات من لوحة التحكم مباشرة (حاليًا بتتحط يدوي في public/images أو تكتبي مسارها في فورم المنتج، زي ما كان في الأصل تقريبًا)
- مراجعة نهائية شاملة للـ Responsive Design على كل صفحة (الكلاسات الأساسية لـ Tailwind متطبقة، لكن مفيش مراجعة بصرية كاملة على كل الشاشات)

## 3) ملحوظة عن Prisma

لو شغّلتي npx prisma generate وطلعلك خطأ شبكة، دا لأني بنيت المشروع في بيئة معزولة مقفول فيها الوصول لسيرفرات تحميل Prisma engines — مش مشكلة في الكود. هيشتغل عادي عندك بعد npm install.

## 4) الصور واللوجو والفيديو

كل الصور واللوجو موجودة زي ما هي في public/images/ — من غير أي تعديل على المحتوى نفسه.
فيديو الهيرو موجود في public/videos/hero.mp4 — لو الفيديو أصلًا portrait (رأسي زي فيديو موبايل)، الصفحة بتعرضه بشكله الطبيعي في النص مع نسخة blurred منه كخلفية، عشان ما يتمططش.

## 5) الخط (Cairo)

الخط بقى self-hosted جوه المشروع (src/fonts/Cairo-Variable.woff2) — مش بيتحمّل من إنترنت خارجي تاني، فمش هيبوظ حتى لو الشبكة مقفولة أو فيها بروكسي.

## 6) قاعدة البيانات (SQLite)

المشروع بيستخدم SQLite — ملف واحد (`prisma/dev.db`) بيتنشئ تلقائيًا أول ما تشغّلي `npx prisma migrate dev`، ومفيش أي سيرفر خارجي أو حساب Supabase/Neon مطلوب. الملف ده مستبعد من git تلقائيًا (`.gitignore`).
